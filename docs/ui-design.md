# 工作台 UI 规范

本次重构参考用户指定的 [SwiftUI Agent Skill / swiftui-pro](https://github.com/twostraws/SwiftUI-Agent-Skill/blob/main/swiftui-pro/SKILL.md)（2026-11-14 读取）。该技能面向 SwiftUI；本项目继续采用 React + Ant Design，将其中的统一设计变量、自适应布局、功能可达性及无障碍原则应用到网页。Swift / iOS API 不适用于本项目。

## 实现约定

- `frontend/src/theme.ts` 集中维护 Ant Design 色彩、字体、圆角、间距及控件主题；`styles.css` 负责应用框架和响应式布局。
- `PageHeader` 统一标题、说明与主要操作；`NavIcon` 提供本地图标，不增加外部依赖。
- 四个工作栏目及角色权限保持原有结构；窄屏通过“打开栏目导航”访问栏目，系统管理、账户操作仍可用。
- 列表表格在自身容器横向滚动，避免将姓名、状态等内容挤成竖排。报告详情和看板在窄屏上下排列。
- 登录页、工作台框架、录像、上传、候选人、产品、题单、报告、看板采用统一样式；其余页面共享控件主题。
- 提供跳转主要内容链接、清晰的键盘焦点、图标按钮名称、候选人详情按钮及减少动画设置支持。

## 业务边界

产品资料仍只有“参考脚本、资料版本、校准状态”三个页签；抽题设置仍在试镜题单流程。四维得分、总档位算法、达标线、Mock / 非正式报告提示及资料版本规则没有改动。

## 验证

运行 `npm run build` 完成 TypeScript 检查和生产构建。现有端到端脚本覆盖角色权限、产品版本、上传、人工评分、报告与录播等流程，并增加 390px 窄屏栏目、产品操作、系统管理入口和页面溢出检查。测试使用隔离数据库及明确启用的 Mock 流程，不是实际主播评分准确性验证。

## 第二轮：按工作任务组织界面

用户反馈上一版更像通用 AI 后台，并确认采用“专业工作台：紧凑表格、清晰状态、直接处理任务”。本轮具体调整：

- 四个工作分组直接列出页面入口，取消分组与页面之间的第二层导航。
- 录像列表增加真实数据计算的任务筛选、候选人/产品/编号搜索、刷新和行内下一步操作；非主要字段放到展开详情，保留查看入口。
- 评委打分时将视频与评分表并排，证据时间可定位该视频；窄屏上下排列。录像元数据默认收起，减少占用。
- 去掉登录宣传语、装饰性品牌图标和侧栏口号，收紧标题、行高和间距，保留圆润控件。

任务数量只统计当前用户可读取的录像；“待我处理”按现有操作权限与录像状态筛选，不代表人员任务分配。接口、评分、发布及权限判断保持原有规则。
